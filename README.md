
# Weekly Note Plugin

## Настройка путей через .env

Плагин использует файл `.env` в корне папки плагина для хранения путей к папке недельных заметок и шаблону:

```
WEEKLY_FOLDER=Mind/Diary
TEMPLATE_FILE=path/to/template.md
```

- **WEEKLY_FOLDER** — папка для недельных заметок
- **TEMPLATE_FILE** — путь к шаблону (может быть пустым)

Изменять эти значения можно через настройки плагина в Obsidian — изменения будут автоматически сохранены в `.env`.

Если `.env` отсутствует, он будет создан автоматически с дефолтными значениями.
